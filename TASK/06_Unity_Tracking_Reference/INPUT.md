# 📥 INPUT: Unity WebGL Tracking Reference

## 🎯 Mục tiêu
Đóng gói và lưu trữ tài liệu, mã nguồn tham khảo cho hệ thống tracking Playable Ads trên nền tảng Unity WebGL để tái sử dụng cho các dự án Unity khác.

## 📋 Yêu cầu chi tiết
1. **Tầng JS Bridge:** File `PlayableBridge.jslib` xử lý MRAID, ExitApi, Mintegral, TikTok.
2. **Tầng C# MonoBehaviour:** File `PlayableAnalyticsManager.cs` quản lý lifecycle, tap counter và `OnApplicationFocus`.
3. **Tài liệu hướng dẫn:** `README.md` mô tả kiến trúc 3 lớp.
