# 📥 INPUT: Fast Build Packaging Tool

## 🎯 Mục tiêu
Thiết lập đường dẫn và công cụ dòng lệnh (CLI tool / script) giúp đóng gói siêu tốc từ `build/web-mobile` sang `build/super-html` mà không cần mở giao diện Cocos Creator Editor.

## 📋 Yêu cầu chi tiết
1. Tạo script standalone: `scripts/fast-super-html.js`.
2. Thêm command vào `package.json`: `npm run pack:super` và `npm run clean:super`.
3. Đo thời gian hoàn thành đóng gói tất cả các kênh (AppLovin, Unity, IronSource, Google, TikTok, Facebook...).
