# 📥 INPUT: Build Web-Mobile & Super-HTML Packaging

## 🎯 Mục tiêu
1. Thực hiện quy trình build project ra nền tảng `web-mobile`.
2. Tiến hành đóng gói tự động Playable Ads qua công cụ `super-html` sang các định dạng Single HTML / Zip cho tất cả các Ad Networks (AppLovin, IronSource, Unity, Google, Facebook, TikTok, Mintegral, Pangle, Moloco, Liftoff, Vungle, Bigo...).

## 📋 Yêu cầu chi tiết
1. Kiểm tra thư mục nguồn `build/web-mobile/`.
2. Kích hoạt module đóng gói `super-html` cho engine Cocos Creator 3.8.8.
3. Xuất toàn bộ file playable ad ra thư mục `build/super-html/`.
