# 📥 INPUT: Cocos Creator MCP Server Integration

## 🎯 Mục tiêu
Cài đặt và thiết lập extension Model Context Protocol (MCP) mã nguồn mở, miễn phí cho Cocos Creator 3.x từ repository `https://github.com/RomaRogov/cocos-mcp.git`.

## 📋 Yêu cầu chi tiết
1. **Clone repository:** Tải mã nguồn `cocos-mcp` vào thư mục `extensions/cocos-mcp` của workspace.
2. **Cài đặt dependencies:** Chạy `npm install` bên trong extension.
3. **Biên dịch extension:** Chạy `npm run build` để xuất mã JavaScript ra thư mục `dist/`.
4. **Chuẩn bị cấu hình:** Cung cấp hướng dẫn kích hoạt trong Editor và cấu hình `mcp_config.json` cho Antigravity IDE.
